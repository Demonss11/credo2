# T-09. `check.run` — исполнение опубликованной версии

- **Статус:** ⬜ открыта
- **Приоритет:** P3
- **Зависит от:** T-06
- **Источник:** Q33 (§4.5).

## Что сделать

- MCP-инструмент `{name, version, input}` — исполняет опубликованную
  версию из `main` (без черновика).
- Ответ — поля объяснения и `name`/`version`.
- Deprecated → `version_deprecated`, отсутствует → `version_not_found`.

## Критерий готовности

Сценарии `../../features/mcp_tools.feature` («check.run исполняет
опубликованную версию», «check.run отклоняет deprecated-версию»,
«check.run требует опубликованную версию»).
