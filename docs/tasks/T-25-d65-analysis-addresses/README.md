# T-25. Снять D65-адреса на разбор T-24 из журнала (Q84/Q85/D87/D88)

- **Статус:** ✅ сделана
- **Приоритет:** P1 (базовый дефект: красный DoD `cargo test --all` на базе
  T-16; `review.md` §«Красный DoD — блокер»)
- **Зависит от:** —
- **Источник:** Q61, [D65](../../decisions/D65-reference-policy.md) (политика
  «время жизни адреса»); базовый P1 приёмки T-16
  (`docs/reviews/T-16-2026-10-02.md`, P1); находка F73 в
  [`findings-registry.md`](../../analysis/findings-registry.md)

## Контекст

Политика [D65](../../decisions/D65-reference-policy.md) п.4 (Q61) запрещает
ссылкам канона адресовать удаляемые/сессионные рабочие данные; на файлы
`docs/analysis/**` ссылки не допускаются (факты живут в Q/D, задачах, фичах;
исключение — живой реестр `findings-registry.md`). Правило проверяет тест
`tests/docs_journal.rs` — `no_addresses_to_removable_or_session_data`.

При приёмке T-16 обнаружен **базовый дефект** (внесён T-15 r9/r10, не T-16):
в живом журнале остались адреса на сессионный разбор
`docs/analysis/T-24-run-2026-10-02-lead-session.md`:

- `docs/questions/Q84.md` — адрес в поле «Связано»;
- `docs/questions/Q85.md` — адрес в поле «Связано»;
- `docs/decisions/D87-t24-pilot-fixes.md` — адрес в «Контексте», «Сверке с
  кодом» и «Ссылках»;
- `docs/decisions/D88-c9-c12-loop-tuning.md` — адрес в «Сверке с кодом» и
  «Ссылках».

Из-за этого `cargo test --all` красный (`docs_journal` — 1 FAILED), и T-16 не
может быть принята до зелёного базового DoD (`review.md` §«Красный DoD —
блокер»). Дефект вне периметра T-16: его файлы (`src/**`, `tests/**`) этих
адресов не содержат; пакеты задачи и правки раздельны (F43).

## Что сделать

1. **Снять адреса на сессионный разбор** из журнала (зона `migrator`,
   `docs/questions/**`, `docs/decisions/**`): адрес
   `docs/analysis/T-24-run-2026-10-02-lead-session.md` убрать; факты и статусы
   сохранить — они живут в `findings-registry.md` (F67–F72) и решениях D87/D88.
   Допустимая форма — ссылка на устойчивый артефакт (реестр) либо снятие адреса
   без потери смысла (образец предыдущих чисток D65, F47/F56).
2. **Синхронизировать журнал:** строка задачи в `docs/TRACEABILITY.md` (равенство
   с реестром `docs/tasks/README.md`, тест T-18); регистрация находки F73 в
   `docs/analysis/findings-registry.md`.
3. **Ничего, кроме адресов, не менять:** формулировки решений D87/D88 по
   существу сохраняются (`.opencode/rules/journal.md` §8 — принятые решения не
   переписываются «задним числом»).

## Критерий готовности

Адресный DoD зелёный: `cargo test --all` без падения
`no_addresses_to_removable_or_session_data` (прогон — `validator`, R2/[D50]);
в живом журнале нет адресов на `docs/analysis/**`, кроме реестра. Ссылки и
статусы синхронны; DoD задачи ([`../README.md`](../README.md) §«DoD для любой
задачи»).

## Примечания

- **Класс** — S: правка только документов журнала (адреса), поведения кода не
  меняет; канон агентов/права не трогает.
- **Границы** — `docs/questions/**`, `docs/decisions/**`,
  `docs/tasks/README.md`, `docs/TRACEABILITY.md`,
  `docs/analysis/findings-registry.md`. `src/**`, `tests/**`, `Cargo.toml`,
  `.opencode/**`, `AGENTS.md`, `docs/features/**` не трогаются.
- **Пакет** — отдельный от T-16 (F43): правка P1 не смешивается с пакетом
  задачи.
- **Прогон** `cargo test --all` выполняет `validator` (R2/[D50](../../decisions/D50-dod-by-package-scope.md));
  роли, работающие с документами, `cargo` не запускают.
- Точные строки — снимок на 02.10.2026; ссылки — по символам, не по номерам
  строк (антипаттерн [§8](../../../.opencode/rules/journal.md)).
