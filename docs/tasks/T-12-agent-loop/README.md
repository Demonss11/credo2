## Контекст

Цикл D38 работает по дисциплине, но не доводит задачу до конца, когда ведёт один
`lead`: разведка канона и смежных карточек съедает шаги родителя, контекст
накапливает весь пилот, scope-решения принимаются в ленте, обрыв сессии не
восстановим. Полный контекст, формулировка решения, следствия и отклонённые
альтернативы — [D39](../../decisions/D39-loop-dispatcher.md);
вопрос — [Q44](../../questions/Q44.md). Класс задачи — **L** (канон и права
`.opencode/**` + `AGENTS.md`, несколько подсистем), потому полный маршрут с
аудитом `auditor` и приёмкой `validator`.
