# T-08. Публикация материализует `rules/{name}.dar`

- **Статус:** ⬜ открыта
- **Приоритет:** P2
- **Зависит от:** —
- **Источник:** Q12, Q33.

## Что сделать

- Если у черновика нет `.dar`-файла, `check.publish` сначала сохраняет
  текст черновика в `rules/{name}.dar`, затем создаёт артефакт.
- Существующий файл не перезаписывается.

## Критерий готовности

Сценарий `../../features/draft.feature` («Публикация черновика без
.dar-файла сохраняет исходник»).

## Design note (решить при реализации)

Поведение при `stale`-черновике (файл новее черновика; Q12: выигрывает
файл) — публиковать файл или требовать пересинхронизации; текущие сценарии
это не покрывают.
