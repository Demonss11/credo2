# T-02. Тест-гейт публикации

- **Статус:** ⬜ открыта
- **Приоритет:** P1
- **Зависит от:** T-01
- **Источник:** Q16, Q34 (SPEC §10 №32).

## Что сделать

- В черновике хранить `last_test_checksum` и `tested_at`.
- Успешный `check.test` обновляет их (`last_test_checksum = source_hash`
  на момент теста).
- `check.publish` отклоняет публикацию без успешного теста и при
  расхождении `source_hash`/`last_test_checksum` (код `publish_failed`,
  T-04).

## Критерий готовности

Сценарии `../../features/test_draft.feature` («Успешный check.test
фиксирует метку тестирования») и `../../features/publish.feature`
(«Запрет публикации без тестирования», «Отклонение публикации при
несовпадении контрольной суммы»).
