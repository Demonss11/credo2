# T-14. GRAMMAR: синхронизация цитаты сообщения парсера

- **Статус:** ⬜ открыта
- **Приоритет:** P2
- **Зависит от:** T-03 (исполнять после реализации)
- **Источник:** [D41](../../decisions/D41-dispatch-refinements.md)
  ([Q46](../../questions/Q46.md)) — находка F11 (меморандум W6, итерация 2).

## Контекст

Run 3 (F11) канонизировал принцип «сообщение парсера — единственный источник
строки ошибки»; сценарий [`draft.feature`](../../features/draft.feature)
(«`check.create` с невалидным source») требует подстроку «отсутствует заголовок
правила». [`GRAMMAR.md`](../../GRAMMAR.md) §2 всё ещё цитирует устаревшую
формулировку «Не найдено имя правила» — дрейф канона языка и сценария.

## Что сделать

- `../../GRAMMAR.md` §2 (таблица «Ограничения v0.1», строка 7): заменить цитату сообщения парсера
  «Не найдено имя правила» → «отсутствует заголовок правила».
- Сверить относительные ссылки в §2.

## Критерий готовности

- §2 (таблица, строка 7) цитирует актуальное сообщение; ссылки живые.
