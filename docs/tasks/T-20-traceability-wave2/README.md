# T-20. Волна 2 `TRACEABILITY`: разбор `open`-строк

- **Статус:** ⬜ открыта
- **Приоритет:** P3 (после демо — «не сейчас», решение владельца 01.10.2026;
  процессная гигиена журнала, продукт не меняет)
- **Зависит от:** —
- **Источник:** [D83](../../decisions/D83-traceability-wave2.md) (Q79);
  связано: [D82](../../decisions/D82-traceability-lifecycle-waves.md) (Q78) —
  волна 1 и словарь `open` · `in work` · `done`

## Контекст

Волна 1 ([Q78](../../questions/Q78.md)/[D82](../../decisions/D82-traceability-lifecycle-waves.md))
перевела [`../../TRACEABILITY.md`](../../TRACEABILITY.md) на словарь
`open` · `in work` · `done`: 28 «точно закрытых» строк → `done`, 26 → `open`.
Статус `open` означает «есть вопрос» (решение не принято либо решение есть, но
требуется задача), но не отвечает, что именно нужно каждой строке для `in work`
или `done`. Владелец (01.10.2026): «волну 2 будем делать не сейчас, а отдельной
задачей». Решение [D83](../../decisions/D83-traceability-wave2.md) оформляет
волну 2 как эту задачу. Полный контекст — [Q79](../../questions/Q79.md).

## Что сделать

1. **Разбор 26 `open`-строк** (Q2–Q4, Q8–Q11, Q14, Q18–Q26, Q30, Q31,
   Q35–Q39, Q63, Q65; перечень — [`../../TRACEABILITY.md`](../../TRACEABILITY.md),
   сверить с раскладкой волны 1 в [D82](../../decisions/D82-traceability-lifecycle-waves.md)):
   по каждой — *основание* (что уже сделано), *остаток* (что осталось),
   *предложение* (задача → `in work` либо закрытие → `done`).
2. **Досье на подтверждение владельцу** — пакет предложений по всем 26 строкам
   (одно решение на строку), до завода задач.
3. **После подтверждения** — завод задач реестра:
   - источник каждой задачи — Q/D-строка журнальной пары;
   - v0.2-остатки — помета «v0.2» в карточке и
     «Зависит от: приёмка v0.1»;
   - закрытия — строки `TRACEABILITY` → `done`.
4. **Синхронизация** — [`../../TRACEABILITY.md`](../../TRACEABILITY.md)
   (статусы и колонка «Задачи»), сводка и карточки
   [`../README.md`](../README.md); строки
   [Q78](../../questions/Q78.md)/[D82](../../decisions/D82-traceability-lifecycle-waves.md)
   и Q79/D83 → `done` (D83, п.5).

## Критерий готовности

- все 26 `open`-строк волны 1 переведены (`in work` — с открытой задачей,
  `done` — при закрытии); строки Q78/D82 и Q79/D83 → `done`;
- каждая заведённая задача имеет источник Q/D и видна через `TRACEABILITY`
  ([D77](../../decisions/D77-tasks-visibility-completeness.md));
- [`../../TRACEABILITY.md`](../../TRACEABILITY.md) и каталоги синхронны;
- правила словаря и теста целостности
  ([D82](../../decisions/D82-traceability-lifecycle-waves.md),
  [T-18](../T-18-docs-journal-test/README.md)) не нарушены (`in work` ⇒ открытая
  задача; `done`/`open` ⇒ открытых задач нет; `resolved` не допускается);
- DoD — [`../README.md`](../README.md) §«DoD для любой задачи» с поправкой
  [D50](../../decisions/D50-dod-by-package-scope.md): код прототипа не меняется →
  `cargo`-прогон не требуется, проверка — документная сверка.
