## Что проверяется

Правка A2 (`"formatter": true` в `opencode.json`) включена, но фактическая
работа `rustfmt` в этой CI-среде не проверялась: харнесс недоступен
(`cargo`/rustfmt отсутствуют; нет сессий OpenCode, запускающих форматтер).

## Протокол smoke (на ближайшем прогоне)

1. Внести косметическое нарушение формата в 1–2 `.rs`-файла (например,
   лишний пробел/несортированные `use`), не коммитить.
2. Выполнить любую запись файла через роль OpenCode → убедиться, что
   форматтер отработал автоматически (файл переформатирован без явного
   `cargo fmt`).
3. Убедиться, что markdown/JSON-файлы при этом **не** изменены (prettier /
   biome не активны без `package.json`).
4. Отозвать тестовые правки (`git checkout -- <файлы>`).

## Критерий выхода

Шаги 2–3 подтверждены в реальном прогоне. Тогда: закрыть флаг в
`wave0-plan.md` (W0-i1, проверка «Правка 1–2 `.rs`-файлов → автоформат»),
записать итог в ленту
[`.opencode/mail/service-mcp-ready.md`](../../../.opencode/mail/service-mcp-ready.md)
и удалить этот файл (или перевести статус в «ЗАКРЫТО» — по решению lead).
