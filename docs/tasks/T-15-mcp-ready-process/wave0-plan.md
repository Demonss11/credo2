- [x] Исключение из среза: `subagent` (передача контекста под-ролям; `task` —

- [x] **Исправление 2026-09-28 (СТОП загрузки):** первая версия была под

  под V2-форму. **Фикс #2:** `ResolveMessage: Cannot find package

  канонический импорт + `Plugin.define` возвращены; после **чистого
  рестарта** — загрузка без ошибок (проверка в логе), боевой срез подтверждён.
  Промежуточные reload-ошибки 19:54 — артефакты ступенчатых правок (watcher
  ловит неполные состояния; правило — править плагин одним атомарным write).
  Диагностика — в ленте; счётчики — на W0-i4.

**Проверки выхода:**

  голова+хвост сохраняет `ERROR` из середины и хвост; для `read` — пометка

- [ ] Боевая проверка на ближайших задачах: крупные выводы (`cargo test`, `rg`)

- [ ] Счётчики растут; экономия фиксируется в ленте T-15 (на W0-i4).
