## Итерация B0-i1 — изоляция и протокол проб

**Вход:** §5 карточки волны; версии (`opencode --version`, `@opencode/plugin`
в `.opencode/package.json`).

**Изменения:**

- [ ] temp-проект `%TEMP%\opencode\wave0b-probe\` (вне репозитория);
- [ ] зафиксировать форму установки V2-плагина (config `plugins` / локальный
  файл) на одном безопасном кандидате;
- [ ] startup-критерий: запуск без ошибок плагина; при падении — фикс или
  красный вердикт;
- [ ] заполнить шаблон протокола в `wave0b-probes.md`.

**Границы:** репозиторий и `.opencode/` не трогаются.

**Проверки выхода:** startup зелёный (или факт ошибки с выводом); протокол
в probes.

**Откат:** удалить temp-проект (вне git).

**Пакет:** без коммита; запись в ленту.
