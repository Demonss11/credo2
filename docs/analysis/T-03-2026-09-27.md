# Досье T-03 — `check.create`: `{name, source}`

- **Дата:** 2026-09-27 · **Итерация:** 1 · **Класс:** M

## Цель

MCP `check.create` принимает **оба** обязательных параметра `name` и `source`,
валидирует заголовок `Правило {name}`, делает upsert черновика и возвращает
`{"status":"ok","name":...}`.

## Текущее расхождение (код ↔ сценарии)

1. Схема инструмента не содержит `name`; `required = ["source"]`.
2. Handler не требует `name` и не сверяет его с заголовком правила.
3. Сообщение при отсутствии заголовка — `"Не найдено имя правила"`, сцена ждёт
   `"отсутствует заголовок правила"`.
4. Ответ `{status, name}` — уже соответствует сценам.
5. Upsert («сохранить = обновить») — уже реализован.
