# D48: Реестр находок — владелец и зона записи

- **Статус:** accepted
- **Дата:** 2026-09-28
- **Resolves:** [Q53](../questions/Q53.md)
- **Спека:** [`SPECIFICATION.md`](../SPECIFICATION.md) §10, решение №48
- **Affects:** [`migrator.md`](../../.opencode/agents/migrator.md) (права, тело);
  [`AGENTS.md`](../../AGENTS.md) §«Рабочая группа агентов» (карта ролей);
  [`findings-registry.md`](../analysis/findings-registry.md) (F39)
- **Tasks:** — (см. «Сверка с кодом»)

## Контекст

При исполнении журнала Run 5 (28.09.2026) `migrator` не смог обновить
[`findings-registry.md`](../analysis/findings-registry.md): фронтматтер роли
запрещал запись в `docs/analysis/**`, хотя инструкции меморандумов адресуют
реестр именно `migrator`. Реестр — точка правды по ID находок, без роли-владельца
он «зависает» между сервисной сессией и `migrator` (F39, аналог F16). Полный
контекст — [Q53](../questions/Q53.md),
[`memorandum-W8-run5.md`](../analysis/memorandum-W8-run5.md) §2 (F39), §5.7.

## Решение

1. **Владелец реестра — `migrator`:** ведёт `docs/analysis/findings-registry.md`
   (внесение находок, ID, обновление статусов по закрытию).
2. **Право** `- { action: edit, resource: "docs/analysis/findings-registry.md",
   effect: allow }` добавлено в `permissions` роли `migrator`.
3. **Синхронизация:** «Пишет в» роли `migrator` в [`AGENTS.md`](../../AGENTS.md)
   дополнено `docs/analysis/findings-registry.md`; тело роли — блок «Реестр
   находок».

## Следствия

- «Инструкция ↔ права» приведены в соответствие: меморандумы адресуют реестр
  роли, которая имеет право его править (F39 закрыт).
- Реестр получает роль-владельца; сервисная сессия больше не правит его в обход.
- Правило «реестр — улика, не канон» (D41) сохраняется: записи не переписываются,
  статусы обновляются по мере закрытия.

## Сверка с кодом

Вердикт: ⚪ **не применимо** — решение о правах и процессе, продуктовое поведение
не меняет. Что проверено (28.09.2026): фронтматтер
[`migrator.md`](../../.opencode/agents/migrator.md) — строка
`edit docs/analysis/findings-registry.md`; [`AGENTS.md`](../../AGENTS.md) —
карта ролей, «Пишет в» у `migrator`; тело роли — блок «Реестр находок»; проба
записи в реестр после правки — успешна (внесены F15–F39). `cargo` не запускался.
Задач не требуется: канон внесён сервисной сессией 28.09.2026.

## Альтернативы

- **Оставить реестр сервисной сессии** (вариант (а) [Q53](../questions/Q53.md)) —
  инструкции продолжают расходиться с правами. Отклонено.
- **Перенести реестр в `docs/questions/`** (вариант (в)) — ломает канон
  расположения улик и существующие ссылки. Отклонено.
