# D94: C11/B2 — профиль-флаг подготовки без включения

- **Статус:** accepted
- **Дата:** 2026-10-03
- **Resolves:** [Q91](../questions/Q91.md)
- **Спека:** —
- **Affects:** [`.opencode/plugins/token-guard.ts`](../../.opencode/plugins/token-guard.ts)

  `.opencode/scripts/token-guard-test.mjs` (новый),
  [`AGENTS.md`](../../AGENTS.md) (§«Гигиена и чтение»),
  [D45](D45-wave0-quality-config.md) (обратная пометка «уточнено D94»),

## Контекст

[D45](D45-wave0-quality-config.md) п.3 отключил B2 — снятие ненужных роли
tool-схем в хуке `session.context` плагина
[`token-guard.ts`](../../.opencode/plugins/token-guard.ts): таблица
`B2_PREFIXES` пуста, условие возврата — прямая экспозиция MCP
(`codemode:false`), тогда же — ревизия правил и тест (F28, закрыт D45).
Черновые правила префиксов сохранены комментарием в файле плагина
(`:132-133`); логика хука не удалена.

Строка `C11` карточки [T-15](../tasks/T-15-mcp-ready-process/README.md) —
«B2 — условие возврата (`codemode:false`)». Владелец 03.10.2026 (сервисная
операция r16) выбрал **подготовить B2, не включая**: иметь правила обоих
профилей и способ активации сменой константы при текущем no-op. Полный
контекст — [Q91](../questions/Q91.md).

## Решение

1. **Профиль-константа.** В
   [`token-guard.ts`](../../.opencode/plugins/token-guard.ts) вводится константа
   **`B2_PROFILE`** со значениями `"off"` (по умолчанию) · `"codemode"` ·
   `"mcp"`.
2. **Таблицы обоих профилей.** `B2_PREFIXES_CODEMODE` и `B2_PREFIXES_MCP` — из
   черновых правил плагина: `docs-writer`/`git` —
   `rust-analyzer`/`rust_analyzer`/`credo`; `analyst` —
   `rust-analyzer`/`rust_analyzer`. Активная таблица выбирается по
   `B2_PROFILE`; `off` — **no-op** (ничего не снимается).
3. **Включение — смена константы, не правка логики.** Переключение профиля не
   трогает хук `session.context`; **B1-срез не меняется**.
4. **Тест** `.opencode/scripts/token-guard-test.mjs` — на синтетических выводах
   профилей (Code Mode и MCP) и `off`: проверяет снятие схем по префиксам и
   no-op `off`. Дом скрипта — служебная зона (запуск владелец/сервисная
   сессия; роль с правом на запуск уточняется при приёмке).
5. **C11 не держит closeout T-15.** Полная готовность C11 (✅) — **внешней
   зависимостью**: включение при прямой экспозиции MCP (`codemode:false`);
   живая проверка — в тот момент. Здесь — состояние «🟡 подготовлен».
6. **Фаза E** (дизайн MCP-сервера) — отдельная задача после заморозки; её вход —
   подготовленный B2.
7. **Карточка T-15:** строка `C11` → «🟡 подготовлен (профиль-флаг, D94);
   включение — `codemode:false`; closeout не держит».

## Следствия

- B2 подготовлен «без включения»: правила обоих профилей и точка переключения
  готовы; в текущем режиме (`codemode:true`) плагин остаётся no-op.
- Включение при прямой экспозиции MCP — правка одной константы; ревизия правил
  и тест к тому моменту уже есть.
- Полный ✅ строки `C11` — внешняя зависимость (`codemode:false`), closeout
  T-15 не блокируется.
- Продуктовый код `src/**` и контракты CREDO не затрагиваются; правки
  `.opencode/**` и `AGENTS.md` — зона сервисной сессии.

## Сверка с кодом

Вердикт: ⚪ **не применимо** (процесс/служебная зона) — решение канонизирует
подготовку B2 в плагине `token-guard` служебной зоны; продуктовый код CREDO и
контракты не меняет.

Что проверено (чтением, 03.10.2026), чем подтверждено:

- **Свобода номеров:** `docs/questions/Q91.md` (создан этим пакетом) и
  `docs/decisions/D94-*`; последние занятые — Q90/D93
  ([`questions/README.md`](../questions/README.md),
  [`decisions/README.md`](../decisions/README.md)); нумерация сквозная (§2
  [`journal.md`](../../.opencode/rules/journal.md)).
- **Состояние B2:** [`token-guard.ts`](../../.opencode/plugins/token-guard.ts) —
  B1-срез активен (`OUTPUT_LIMIT`/`sliceText`, хук `execute.after`); B2-таблица
  `B2_PREFIXES` пуста, логика хука `session.context` присутствует, черновые
  правила — комментарием (`:132-133`).
- **Условие возврата:** [D45](D45-wave0-quality-config.md) п.3 (B2 отключён,
  возврат при `codemode:false`); [F28](../analysis/findings-registry.md) —
  закрыт D45.
- **Периметр правок:** `.opencode/**`, `AGENTS.md` — зона сервисной сессии
  ([`AGENTS.md`](../../AGENTS.md) §«Служебная зона и аудит»); правки вносятся
  отдельно от журнала.

`cargo` не запускался (§5.3, [D50](D50-dod-by-package-scope.md)): решение
процессное, кода CREDO не касается; адресный прогон (в т.ч. теста профилей) —
за `validator` на приёмке (R2).

**Задача —** [T-15](../tasks/T-15-mcp-ready-process/README.md): решение
легитимирует подготовку строки `C11` (фаза C) в рамках программы.

## Альтернативы

- **Runtime-выбор профиля (storage/env, вариант B Q91)** — отклонён: лишняя
  поверхность настройки в служебной зоне при одноразовом включении.
- **Оставить прозу D45 (вариант C Q91)** — отклонён: подготовка не выполнена,
  включение потребует правки логики, а не смены константы.
