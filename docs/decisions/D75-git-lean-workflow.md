## Контекст

Разбор шести пакетов роли `git` за 29.09.2026 (инструмент
`.opencode/scripts/session-analysis`): **117 шагов**, **201 вызов** (130 shell),
`cache.read` **3.52M**, ~**$0.084**; дороже всех — коммит одного файла
(20 шагов / 43 вызова / 12 528 reasoning). Избыточны: `git ls-files --eol` и
байтовые чтения newline, `git diff --check`, `git show --stat`, пост-push
`status`/`log`, серии `git log --all --grep`; чтения ленты/памяти целиком
(до ~60 КБ); промпт `lead` дублирует состав пакета. Основной расход —
`cache.read` (контекст × шаги). Независимый аудит `auditor` подтвердил гипотезы
и оценил диапазон сокращения **−75–85%** при полном наборе. Полный контекст —
[Q71](../questions/Q71.md).

## Решение

1. **Минимальный цикл пакета** (процессный коммит): `git status -sb` →
   `git log -1 --oneline` (идемпотентность одной проверкой) → записи до `add`
   (F43) → `add` точными путями → `git diff --cached --name-status` → `commit` →
   `push`; ответ — текстом, **post-push git-команд нет**.
2. **Запрещены как избыточные:** `git ls-files --eol` и байтовые чтения newline,
   `git diff --check`, `git show --stat`/`git diff --stat`, серии
   `git log --all --grep` (при необходимости — одна проверка, шаблон в кавычках),
   пост-push `status`/`log`.
3. **Чтения — только хвосты** ленты и памяти (`offset`/`limit`); записи — по
   шаблону.
4. **Шаблон промпта `lead`** (в `git-workflow.md`): 5–8 строк — операция, ссылка
   на запись пакета в ленте (состав не дублировать — Q41), база `HEAD`, режим
   («коммит + push»), сообщение коммита.
5. **Хелпер `.opencode/scripts/git-check.mjs`** (read-only: `status -sb` +
   `log -1` + опция `--staged` со списком/счётом) — allowlist у роли;
   синхронизировать `review.md` §«Доступные команды».
6. `steps` роли `git`: **28 → 14** (уточнено 30.09.2026: **18** — см.
   «Следствия»).
7. `memory/git.md` (602 строки) — урезать до короткой памятки (правит сервисная
   сессия, F35).

## Следствия

- Минимальный цикл и хвостовые чтения дают ожидаемое сокращение: shell −72%,
  шаги −59%, токены −75–85% (оценка `auditor`).
- Хелпер — новая поверхность: read-only; изменяющие команды остаются под `ask`
  (скрипт с `add`/`commit` отклонён — обходил бы подтверждения).
- Правки канона агентов (`.opencode/**`) — по протоколу сервисной сессии:
  журнал → правки → аудит `auditor` → приёмка `validator`.
- Урезание `memory/git.md` — режим F35 (память-знание + хвост чекпойнтов;
  хроника — `state/`/лента).
- Гарантии процесса сохраняются: подтверждение по ленте, идемпотентность,
  записи пакета до коммита (F43).
- **Обновление 30.09.2026 — проверка сессии (session-analysis):** уточняет п.1
  (формы команд) и п.6 (`steps`):
  - **точные формы команд:** `git add` — пути с точкой с `./`-префиксом и
    **без `--`**; сверку staged — **отдельным шагом после `add`** (не в одном
    батче — гонка индекса);
  - **стартовое чтение роли `git` — минимум** (хвост памяти, §цикла/§пакета
    правила, хвост ленты); подтверждение владельца — по точному адресу записи из
    промпта `lead` (повторно по лентам не искать);
  - `steps` роли — **18** (пакет из двух коммитов без обрыва);
  - **шаблон промпта `lead` усилен:** состав/команды/числа не дублировать,
    подтверждение — с точным адресом;
  - **практика:** сервисные волны — **один коммит** (канон + записи); отдельный
    `chore(process)` — для кодовых задач ([D46](D46-product-process-commits.md));
  - источник фактов — разбор сессии (session-analysis; артефакты вне
    репозитория), без ссылок на `mail/**` ([D65](D65-reference-policy.md)).

`cargo` не запускался (§5.3, [D50](D50-dod-by-package-scope.md)): решение
процессное, кода прототипа не меняет; адресный прогон не требуется.

**Задач не требуется:** правки — в служебной зоне (`.opencode/**`), исполняются
сервисной сессией по тексту решения; правки канона — по протоколу (аудит
`auditor`, приёмка `validator`).

## Альтернативы

- **Без хелпера** — отклонено: не достигается целевое сокращение (−85–90%).
- **Скрипт с `add`/`commit`** — отклонено: обходит `ask`-подтверждения.
- **Только чек-лист** — отклонено: не снимает дорогие чтения и дублирующий
  промпт.
- **Не менять** — отклонено: избыточные shell-проверки и контекст × шаги
  остаются основным расходом.
