## Контекст

[`GRAMMAR.md`](../GRAMMAR.md) — 99 строк, канон языка v0.1 (EBNF включён). Наряду
с нормативом (EBNF, ограничения, ключевые слова) файл несёт rationale: §3
«Стратегия LSP-совместимости» (~21 строка), шапка «Статус» (~9 строк), §4/§5 —
источники и план (~12 строк). Есть Q-упоминания (Q2/Q3/Q4, Q36–Q39), что
расходится с политикой «ссылка, не копия» ([D65](D65-reference-policy.md)) и
ревизией SPEC ([Q66](../questions/Q66.md)). Обоснования уже закреплены:
regex-минимум/лексер-AST — [D16](D16-dsl-canon-regex-mvp.md), поведение при
падении LSP — [D6](D6-lsp-degradation.md). Полный контекст — [Q70](../questions/Q70.md).

## Решение

1. **Нормативный минимум:** EBNF, ограничения v0.1, ключевые слова, план v0.2 —
   **списком**.
2. **Rationale убрать/сжать до ссылок:** шапка «Статус», §3 «Стратегия
   LSP-совместимости», §4/§5 (источники/план) → ссылки на
   [D16](D16-dsl-canon-regex-mvp.md)/[D6](D6-lsp-degradation.md).
3. **Q-ссылки снять** (кроме необходимого минимума).
4. Ориентир объёма — **−~42 строки**.

## Следствия

- `GRAMMAR.md` — нормативный документ языка; обоснования — в журнале
  ([D16](D16-dsl-canon-regex-mvp.md)/[D6](D6-lsp-degradation.md)).
- Требуется согласование ссылок с ревизией SPEC ([D70](D70-spec-reduction.md)),
  чтобы не разъехаться в указателях на канон языка.
