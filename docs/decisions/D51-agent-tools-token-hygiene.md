# D51: Инструменты экономии токенов ролей — сводка прав и каноничный подсчёт строк

- **Статус:** accepted
- **Дата:** 2026-09-29

- **Tasks:** — (см. «Сверка с кодом»)

## Контекст

Две проверки ролей расходовали ресурс (`steps`/токены,
[D44](../decisions/D44-run5-refinements.md)) без пользы либо были невыполнимы:

- **Подсчёт строк.** Составная команда PowerShell
  (`powershell -Command "… | Measure-Object …"`) отклоняется правами как
  составная — `docs-writer` получил `Permission denied`; одиночной каноничной
  формы не было закреплено.
- **Машинная сверка прав.** Сырой `opencode debug agents` — JSON-массив
  18 агентов (122 511 Б / 2617 строк) с полными `system`-промптами; срез
  token-guard, полный файл ролям недоступен. `auditor` и `validator` держали
  команду в allowlist и инструкциях, но фактически читали срез.

Полный контекст — [Q56](../questions/Q56.md), лента
[`service-agent-tools.md`](../../.opencode/mail/service-agent-tools.md).

## Решение

1. **Скрипт-обёртка `.opencode/scripts/agents-perms.mjs`** — основной инструмент
   машинной сверки прав. Печатает компактную сводку (≈3–4 КБ (11 ролей): роль,
   режим, `steps`, shell-права `allow`/`ask`); режимы `--role <имя>`,
   `--grep <подстрока>`, `--json`; встроенные агенты отфильтрованы по умолчанию.
   Скрипт живёт в репозитории (аудируем) и заменяет сырой вывод.
2. **Сырой `opencode debug agents` убирается** у `validator` и `auditor`
   (allowlist `validator`/`auditor`, шаг 4 чек-листа `auditor` и шаблон его
   отчёта). При сбое скрипта — **эскалация** (вопрос вызвавшему/`lead`), а не
   возврат к дорогой команде.
3. **Каноничная форма подсчёта строк — `rg -c '^' <файл>`**: одиночная команда,
   `rg` есть у всех ролей; закрепляется в
   [`workspace.md`](../../.opencode/rules/workspace.md) §«Как искать». Форма
   `rg -c ""` в PowerShell теряет пустой аргумент — не использовать.
4. **Синхронизация канона** (вносит сервисная сессия владельца, не `migrator`):
   правки `validator.md`, `auditor.md`, `review.md`, `workspace.md`, а также
   [`AGENTS.md`](../../AGENTS.md) §«Служебная зона» (после `reload` — машинная
   сверка через `node .opencode/scripts/agents-perms.mjs`, ожидание
   `agents: 11 из 18`) + новый скрипт — отдельными шагами после журнала.

## Следствия

- Машинная сверка прав сохраняется, но становится дешёвой: ≈3–4 КБ сводки
  (11 ролей) вместо 122 КБ JSON, без среза token-guard.
- Скрипт — артефакт репозитория: аудируем, воспроизводим, версионируем.
- Убирание сырой команды у `validator`/`auditor` снимает соблазн дорогого вывода;
  при сбое скрипта — эскалация, а не обход.
- Подсчёт строк унифицируется: `rg -c '^' <файл>` доступен всем ролям, составные
  powershell-формы больше не нужны.
- Расхождение канона (allow-листы/инструкции) устраняется синхронизацией
  сервисной сессией; до внесения тексты остаются историческими.

## Сверка с кодом

Вердикт: ⚪ **не применимо** — решение процессное/инструментальное, продуктовое
поведение и код `src/**` не меняет (образцы —
[D50](../decisions/D50-dod-by-package-scope.md),
[D49](../decisions/D49-validator-branch-contains.md)).

Что проверено (29.09.2026, файлами и замерами):
- право `opencode debug agents` в каноне:
  [`review.md`](../../.opencode/rules/review.md) стр. 32, 86, 92;
  [`validator.md`](../../.opencode/agents/validator.md) стр. 21;
  [`auditor.md`](../../.opencode/agents/auditor.md) стр. 25 (+ инструкции
  стр. 151–152, 178) — ревизия совпадает с лентой (номера строк — снимок на
  момент ревизии 29.09.2026, до правок D51);
- замеры (сервисная сессия): `opencode debug agents` → **122 511 Б / 2617 строк**
  (JSON-массив 18 агентов `id,name,model,request,system,description,mode,hidden,color,steps,permissions`);
  прототип сводки → **1 883 Б** (18 строк);
  `rg -c '^' .opencode/mail/service-dod-scope.md` → **272** (рабочая форма);
  `rg -c ""` в PowerShell теряет пустой аргумент — не использовать.

Смоук скрипта (`--role`, `--grep`, `--json`) — на приёмке (`validator`).
`cargo` при подготовке записи не запускался. Задач не требуется: скрипт и правки
канона вносят сервисная сессия владельца, аудит — `auditor`, приёмка —
`validator`; продуктовый код и `tests/**` не затрагиваются.

## Альтернативы

- **Оставить как есть** (вариант (а) [Q56](../questions/Q56.md)) — powershell-подсчёт
  (отклоняется правами) и сырой `opencode debug agents` (срез, полный файл
  недоступен). Отклонено: проверки дороги или невыполнимы, ресурс роли тратится
  впустую.
- **Отказаться от машинной сверки прав** (вариант (в)) — сверка по текстам
  вручную. Отклонено: сверка ловит реальные расхождения прав и инструкций
  (аналоги F16/F39); вариант (б) сохраняет её, лишь удешевляя.
