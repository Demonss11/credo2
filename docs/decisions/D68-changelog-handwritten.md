# D68: `CHANGELOG` — рукописный; генератор отклонён

- **Статус:** accepted
- **Дата:** 2026-09-29
- **Resolves:** [Q64](../questions/Q64.md)
- **Спека:** [`SPECIFICATION.md`](../SPECIFICATION.md) §10, решение №68
- **Affects:** [`CHANGELOG.md`](../CHANGELOG.md) (сохраняется рукописный канон;
  владелец [`docs-writer`](../../AGENTS.md));
  [`D46`](D46-product-process-commits.md) (формат коммитов); обзор
  [`doc-quality-checks-2026-09-29.md`](../research/doc-quality-checks-2026-09-29.md);
  согласовано с [D66](D66-doc-quality-checks.md)
- **Tasks:** — (см. «Сверка с кодом»)

## Контекст

Кандидат `generate_changelog` требует конвенции коммитов
`[компонент] тип: описание`. У нас — `docs(D61–D65): …` (конвенция иная,
[D46](D46-product-process-commits.md)) и рукописный [`CHANGELOG.md`](../CHANGELOG.md)
(нарратив + ссылки; владелец `docs-writer`). Обзор отмечает конфликт с «один
писатель на файл» и владением каноном, а не дубль. Полный контекст —
[Q64](../questions/Q64.md).

## Решение

1. **Сохраняем рукописный [`CHANGELOG.md`](../CHANGELOG.md)** — владелец
   `docs-writer`, нарратив и ссылки на решения.
2. **Текущий формат коммитов сохраняется** ([D46](D46-product-process-commits.md)).
3. **`generate_changelog` не берём.**

## Следствия

- Канон [`CHANGELOG.md`](../CHANGELOG.md) остаётся за одним писателем
  (`docs-writer`) и не переписывается автоматически.
- Конвенция коммитов не меняется — миграционных правок истории не требуется.
- Нарратив и обоснования решений сохраняются (они не выводятся из subject'ов).
- **Обновление 29.09.2026:** область ведения дополнена — фиксируются **только
  кодовые изменения продукта**; правки документации/процесса в `CHANGELOG` не
  попадают (история — git и журнал Q/D); см. [D72](D72-changelog-full-cleanup.md).

## Сверка с кодом

Вердикт: ⚪ **не применимо** (процесс/документы) — генератор не вводится, кода
прототипа не меняет.

Что проверено (чтением, 29.09.2026), чем подтверждено:

- **[`CHANGELOG.md`](../CHANGELOG.md) существует и рукописный:** нарратив +
  ссылки на решения (`docs/`, `decisions/`, задачи) — внешний вид не
  генерируемый из commit-subject.
- **Конвенция коммитов иная:** [D46](D46-product-process-commits.md) —
  продуктовые/процессные коммиты (`docs(Qn):`/`feat:`), а не `[компонент] тип:`.
- **Скрипта-генератора нет:** обзор `glob .opencode/scripts/**` →
  `clean-logs.mjs`, `agents-perms.mjs`, `session-analysis/**`;
  `generate_changelog.mjs` отсутствует.
- **Опора:** обзор [`doc-quality-checks-2026-09-29.md`](../research/doc-quality-checks-2026-09-29.md)
  — раздел «Не применимо и почему» (автогенерация → «один писатель на файл»,
  владение `docs-writer`, иная конвенция).

`cargo` не запускался (§5.3, [D50](D50-dod-by-package-scope.md)): решение
документное, кода не касается; адресный прогон не требуется.

**Задач не требуется:** рукописный `CHANGELOG.md` сохраняется как есть; отказ от
генератора не порождает работ по коду прототипа.

## Альтернативы

- **Конвенция `[компонент] тип:` + генератор** — отклонено: перестройка формата
  коммитов ([D46](D46-product-process-commits.md)) и потеря нарратива/обоснований.
- **Гибрид (генерация черновика)** — отклонено: дублирование и лишний контур
  синхронизации при живом рукописном каноне.
