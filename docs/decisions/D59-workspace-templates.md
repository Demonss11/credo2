## Контекст

`notebook_ui.feature` создаёт `rules/` и `README.md` (после Q34/Q37 — без
`tables/` и `tests/`), но содержание README и шаблона нового правила не было
задано нигде. Грозили две ошибки: шаблон с плейсхолдерами, не проходящий
regex-парсер v0.1, и README, дублирующий файл-пример. Полный контекст —
[Q35](../questions/Q35.md).

## Решение

1. **Новый workspace** создаёт:
   - `rules/` — каталог исходников правил;
   - `rules/Пример.dar` — канонический пример из
     [`GRAMMAR.md`](../GRAMMAR.md) §1;
   - `README.md` — структура workspace, пример и шаги «создать → выполнить →
     опубликовать»; **ссылается** на файл-пример, а не дублирует его;
   - `.gitignore` с записями `.credo/` и `.dar-notebook/` ([Q19](../questions/Q19.md),
     [D58](D58-workspace-data-dirs.md)).
2. **«Создать правило»** создаёт файл `rules/{Имя}.dar` с **парсящимся**
   шаблоном. Имя правила в шаблоне = имя файла; имя проверяется по грамматике
   v0.1 (буквы/цифры/`_`, включая кириллицу,
   [`GRAMMAR.md`](../GRAMMAR.md) §1). Плейсхолдеры вроде `Поле < Значение`
   запрещены — regex-парсер v0.1 сразу дал бы красную диагностику.

   Канонический шаблон (`{Имя}` подставляется из диалога):

   ```dar
   // Новое правило: отредактируйте условие и решение
   Правило {Имя} {
     Если (Клиент.Возраст < 21) {
       Решение = Отказ;
       Причина = "Причина отказа";
     }
   }
   ```
3. **Черновик при создании файла не создаётся** — он появляется при
   сохранении/тестировании (draft-first, [Q33](../questions/Q33.md)); кнопка
   «Выполнить» активируется после появления черновика.
4. **Шаблон согласован с [`GRAMMAR.md`](../GRAMMAR.md) v0.1:** одно сравнение,
   `Решение = …;`, `Причина` — строка; допускается комментарий `//`.

## Альтернативы

- **Оставить README и шаблон без описания** — отклонено: пробел в документации;
  поведение Notebook было бы неопределённым.
- **Шаблон с плейсхолдерами** (`Поле < Значение`) — отклонено: regex-парсер
  v0.1 сразу дал бы красную диагностику; шаблон должен парситься.
- **Создавать черновик при создании файла** — отклонено: нарушает draft-first
  ([Q33](../questions/Q33.md)); черновик — производное состояние по сохранению
  ([Q12](../questions/Q12.md)).
- **Дублировать пример правила в README** — отклонено: README ссылается на
  `rules/Пример.dar` (один факт — один канон, Q41).
- **Не создавать `.gitignore` при создании workspace** — отклонено: `.credo/`
  и `.dar-notebook/` загрязняли бы git-статус пользователя
  ([Q19](../questions/Q19.md), [D58](D58-workspace-data-dirs.md)).
