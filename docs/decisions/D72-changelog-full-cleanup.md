# D72: `CHANGELOG` — полная очистка; далее только кодовые изменения

- **Статус:** accepted
- **Дата:** 2026-09-29
- **Resolves:** [Q68](../questions/Q68.md)
- **Спека:** — (§10 упраздняется решением [D70](D70-spec-reduction.md))
- **Affects:** [`CHANGELOG.md`](../CHANGELOG.md) (полная очистка записей);
  [`D68`](D68-changelog-handwritten.md) (дополняется областью ведения)
- **Tasks:** — (см. «Сверка с кодом»)

## Контекст

[`CHANGELOG.md`](../CHANGELOG.md) — 599 строк: «Документация» ≈424 строки,
«Процесс» ≈110, кодовый блок ≈58 (Добавлено 28 / Исправлено 8 / Ломающие 22).
Документные и процессные разделы — миграционный осадок (есть устаревшее, например
запись «`auditor` правит канон»); хронология прототипа дублирует журнал и
git-историю. [D68](D68-changelog-handwritten.md) закрепляет рукописный формат
(генератор из коммитов отклонён). Развилка «полная очистка теряет единственную
запись о ломающих изменениях контрактов» закрыта владельцем в пользу полной
очистки: история — git/журнал. Полный контекст — [Q68](../questions/Q68.md).

## Решение

1. **Удалить все записи** `CHANGELOG.md`; файл — заголовок +
   `## 0.1.0 (в разработке)` (пусто). История — git и журнал Q/D (решение
   владельца 29.09.2026).
2. **Правило ведения:** фиксируем **только кодовые изменения продукта**;
   документные и процессные изменения — нет.
3. Версия `0.1.0 (в разработке)` сохраняется как текущая.
4. [D68](D68-changelog-handwritten.md) **дополняется областью** (что фиксируем);
   отклонение генератора из коммитов — в силе.

## Следствия

- Документные/процессные записи и кодовый блок удаляются без переноса; провенанс —
  git-история и [`decisions/`](README.md).
- Запись о ломающих изменениях контрактов (REST/MCP) уходит из документа (выбор
  владельца); её источник — [D25](D25-rest-error-envelope.md)/[D34](D34-mcp-tool-contracts.md)
  и задачи T-03/T-04.
- Правило «только кодовые изменения» согласуется с рукописным форматом
  ([D68](D68-changelog-handwritten.md)) и владельцем `docs-writer`.

`cargo` не запускался (§5.3, [D50](D50-dod-by-package-scope.md)): решение

## Альтернативы

- **Сохранить сжатую кодовую выжимку (~30 строк)** — отклонено владельцем:
  история — git/журнал; дублировать её в `CHANGELOG` не нужно.
- **Не трогать** — отклонено: миграционный осадок и устаревшие записи.
