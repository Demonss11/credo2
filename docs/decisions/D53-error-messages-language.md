## Контекст

Фичи ожидали русские тексты ошибок, код частично отвечал английским
(`not found`, `missing or invalid x-api-key`, `unknown tool`); не было единого
правила, что писать по-русски, а что латиницей. Полный контекст —
[Q11](../questions/Q11.md).

## Решение

1. **Принцип «машина / человек»** (сквозной для Q11, Q13, [Q42](../questions/Q42.md)):
   - человекочитаемый текст ошибки (`message`) — **русский**;
   - машиночитаемое (идентификаторы проверок `name`, коды ошибок, ключи JSON,
     сегменты путей) — **латиница**.
2. **Канонические тексты и статусы REST** (пути и ресурсы — по решению Q20):

   ```
   404  проверка не найдена: {name}
   404  версия не найдена: {name}@{version}
        — POST /checks/{name}/versions/{version}/evaluate
   410  версия выведена из эксплуатации: {name}@{version}
        — обращение к deprecated-версии
   409  активация недоступна: {name}
        — active-эндпоинт при пустом active (все версии deprecated, Q21)
   401  ошибка аутентификации: неверный или отсутствующий x-api-key
        — фиксировано решением Q22 (заголовок x-api-key)
   ```

   410 (Gone) и 409 (Conflict) зафиксированы 2026-09-25.
3. **Границы решений** (чтобы не дублировать канон): Q11 — язык и сами тексты
   `message`; Q23 — конверт и коды ошибки (`{"error": {"code", "message"}}`);
   Q22 — заголовок и тексты 401.
4. **Исключения канона:** служебные и диагностические сообщения (ошибки git в
   `lib.rs`, описания в OpenAPI-документе) остаются техническими.
5. **Ядро, публикация и MCP** уже соответствуют канону (приведены при Q8/Q9);
   транспорт REST приведён к точному тексту «проверка не найдена: {name}».

## Следствия

- Человекочитаемый слой REST/MCP — русский, машинный контракт (`code`, ключи,
  `name`, сегменты путей) — латиница; клиент различает ошибки по `code`, а не по
  тексту.
- Тексты REST закреплены в §4.4 (таблица статус/`code`/`message`), ключи и
  тексты MCP — в §4.5; краткий канон решения — §10 №53.
- Шапочные пометки Q11 в `evaluate.feature` / `rest_api.feature` /
  `rest_auth.feature` / `errors.feature` фиксируют канон (правки — зона
  `docs-writer`).
- Резерв `version_deprecated` в MCP (код есть, путь `check.run` вне MVP) —
  известный и покрыт [T-09](../tasks/T-09-check-run/README.md) / Q33.

## Альтернативы

- **Латиница для всего** (вариант (а) [Q11](../questions/Q11.md)) — привычно
  инструментам, но теряется человекочитаемый слой для риск-технолога; ключевая
  аудитория — банковские аналитики. Отклонено.
- **Русский текст вперемешку с латиницей по месту** (вариант (в)) — кодам и
  ключам JSON грозит дрейф, машинная обработка ломается. Отклонено.
- **Оставить английский в коде при русских фичах** — фактическое состояние до
  решения; противоречит Q41 (расхождения не «молчат»). Отклонено.
- **Транслитерация кодов ошибок** — ухудшает машинный контракт; коды —
  латиница `snake_case`, текст — русский (выбрано).
