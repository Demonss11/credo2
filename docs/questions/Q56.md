# Q56: Какими инструментами роли экономят токены при проверках (подсчёт строк; машинная сверка прав)?

## Контекст

Две проверки ролей устроены расточительно:

1. **Подсчёт строк файла.** Каноничной формой роли пытались применять
   составную команду PowerShell (`powershell -Command "… | Measure-Object …"`),
   но она отклоняется правами как составная (`docs-writer` —
   `Permission denied`). Нужна одиночная форма, доступная всем ролям.
2. **Машинная сверка прав агентов.** `auditor` сверял права через сырой
   `opencode debug agents`: это JSON-массив 18 агентов (122 511 Б / 2617 строк)
   с полными `system`-промптами; вывод срезается token-guard, полный файл
   ролям недоступен — сверка фактически выполняется вслепую и дорого.

Обе проблемы — про ресурс роли (`steps`/токены, [D44](../decisions/D44-run5-refinements.md));
проверки при этом содержательные: машинная сверка ловит реальные расхождения
прав и инструкций.

## Вопрос

Какими инструментами роли экономят токены при проверках — подсчёте строк файла
и машинной сверке прав агентов?

## Варианты

- (а) **оставить как есть** — составные powershell-подсчёты (отклоняются
  правами) и сырой `opencode debug agents` (122 КБ, срез); просто, но проверки
  дороги или невыполнимы;
- (б) **скрипт-обёртка + каноничная форма подсчёта** — новый
  `.opencode/scripts/agents-perms.mjs` (сводка ≈3–4 КБ (11 ролей): роль, режим,
  `steps`, shell-права `allow`/`ask`; режимы `--role <имя>`, `--grep <подстрока>`,
  `--json`, фильтр встроенных агентов по умолчанию) как **основной инструмент**
  машинной сверки прав; сырой `opencode debug agents` **убрать** из allow-листов
  и инструкций `validator` и `auditor` (при сбое скрипта — эскалация); подсчёт
  строк — одиночная форма `rg -c '^' <файл>`;
- (в) **отказаться от машинной сверки прав** — сверять по текстам вручную;
  дешевле по токенам, но сверка перестаёт ловить реальные расхождения прав и
  инструкций (её смысл теряется).

## Рекомендация

Вариант (б): сводка-скрипт даёт ту же машинную сверку за ≈3–4 КБ (11 ролей)
вместо 122 КБ (в десятки раз дешевле), остаётся в репозитории и аудируема; сырой
`opencode debug agents` избыточен и срезается — убирается у `validator` и
`auditor`. Каноничная форма подсчёта строк — `rg -c '^' <файл>`: одиночная
команда, доступна всем ролям (проверено: `272` строки в ленте
сервисной сессии `.opencode/mail/**`).
