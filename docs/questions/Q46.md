## Контекст

Третий прогон цикла диспетчера ([D39](../decisions/D39-loop-dispatcher.md)) на
задаче T-03 отработал первую итерацию до приёмки, но выявил серию процессных
расхождений с каноном (`dispatch-loop.md`, `AGENTS.md`, роли):

- **F1** — `analyst` исключил роль `rust-expert` из маршрута M с обоснованием,
  которого канон для M не допускает;
- **F4** — команды `git ls-remote`/`git diff --stat` отклонены движком прав,
  хотя соответствуют allow-паттернам (семантика матчинга не выяснена);
- **F5** — `current_state.yaml` отстаёт от факта (авторитет состояния не задан);
- **F8**/F12 — вопросы владельцу задавались текстом, а не через `question` tool,
  и канал не фиксировался;
- **F9** — git-пакет пропустил файл; сверки пакета с деревом не было;
- **F10** — частичное исполнение пакета и override владельца каноном не описаны;
- **F13** — финальный re-plan не оставил записи `progress.yaml` (сессия упала на
  лимите шагов).

Плюс предложения W7 §2–§4 (mail/memory, порог меморандума, реестр находок,
pre-flight, терминология) и ответы владельца W7 §8.

## Вопрос

Какие уточнения канона цикла диспетчера нужны по итогам Run 3, чтобы Run 4
(T-03 заново) не повторил те же расхождения, — и как их оформить?

## Варианты

- (а) **оставить как есть, ограничиться реестром находок** — расхождения
  повторятся в Run 4, находки останутся устными;
- (б) **точечные правки по каждой находке без свода** — разрозненные правки
  `dispatch-loop.md`, `AGENTS.md` и ролей плодят дрейф «инструкция ↔ права»
  (риск Н3 из T-11);
- (в) **единый пакет уточнений `dispatch-loop`** (плюс `AGENTS.md`, роли,
  `git-workflow.md`, шаблоны памяти, артефакты `docs/analysis/**`) — оформляется
  одним решением D41 и реализуется одной задачей T-13; GRAMMAR §7 (F11) —
  отдельной docs-задачей T-14.

## Рекомендация

Вариант (в): уточнения относятся к одному канону (цикл диспетчера), их источник —
один прогон; отдельные решения по каждой находке дублировали бы контекст и
рождали бы расхождения. Реестр находок (`findings-registry.md`) при этом
сохраняет память о каждой находке, а pre-flight чек-лист страхует прогон.
