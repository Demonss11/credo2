## Контекст

Проект обслуживался только агентной средой OpenCode: MCP-сервер `credo` описан в
`opencode.json` (проверка — `opencode mcp list`). Владелец попросил адаптировать проект
к работе и с **Koda CLI** (`@kodadev/koda-cli` 1.2.1) — AI-ассистентом в терминале с
поддержкой MCP (stdio) и памяти через `AGENTS.md`.

Разведка (npm-пакет, бандл `koda.js`, живые команды) подтвердила:

- конфигурация MCP — ключ `mcpServers` в `~/.kodacli/settings.json` (user) или
  `.kodacli/settings.json` (project); поля сервера: `command`, `args`, `env`, `trust`,
  `timeout`, `includeTools`/`excludeTools`;
- CLI-обвязка: `koda mcp add|remove|list` (наследие gemini-кодовой базы, `--transport
  stdio`, разделитель `--` перед args команды);
- **баг 1.2.1:** `koda mcp add` не сохраняет позиционные args в `settings.json`
  (записывает `"args": []`) — конфиг нужно дописывать вручную;
- память: Koda читает `AGENTS.md` (уже канон проекта) — отдельный `KODA.md` не нужен;
- `credo2` пишет логи только в stderr, stdout чист — stdio-транспорт безопасен;
  `--workspace` по умолчанию = `current_dir`, но в конфиге надёжен абсолютный путь.

Попутно обнаружилось: пути в `opencode.json` устарели (перенос репозитория
`D:/pyTechNotes/.../prototypes/credo2` → `C:/Users/Demon/pytechnotes/dar/credo2`) —
MCP-контуры обоих клиентов были нерабочими до починки.

## Вопрос

Как оформить адаптацию проекта под Koda CLI, чтобы: (а) не раздувать канон лишней
памятью (`KODA.md`), (б) конфиг `.kodacli/settings.json` был воспроизводим, (в) оба
клиента (OpenCode и Koda) ссылались на один и тот же бинарь и workspace?

## Варианты

- **(A) Проектный `.kodacli/settings.json` + правка `opencode.json` + строка в
  `AGENTS.md`.** Минимальный след: конфиг Koda в репозитории (project scope), проверка
  `koda mcp list`, карта репозитория дополняется строкой `.kodacli/`.
- **(B) User-scope (`~/.kodacli/settings.json`).** Не попадает в git, но теряется
  воспроизводимость для других машин/агентов.
- **(C) Только документация (как подключать), без конфига.** Нулевой след, но каждый
  раз ручная настройка.

## Рекомендация

Вариант **(A)** — принят владельцем 04.10.2026: `.kodacli/settings.json` в репозитории
с абсолютным путём к `target/release/credo2.exe` и `--workspace`; `opencode.json`
чинится на текущие пути; `AGENTS.md` получает строку карты и команду проверки
`koda mcp list`. `KODA.md` не вводится — `AGENTS.md` уже является общей памятью
(обе среды его читают). Оформлено [D99](../decisions/D99-koda-mcp-adapter.md).
