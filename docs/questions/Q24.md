## Контекст

`batch.feature` шлёт `{"заявки": [...]}` на тот же `POST .../evaluate` и ждёт
ответ «статистика/всего/отказано/одобрено». Схема запроса и ответа нигде не
описана, ключи русские — вразрез с остальным API (машинные ключи — латиница,
Q11).

## Вопрос

Отдельный `POST /checks/{name}/versions/{v}/batch` или перегрузка `evaluate`?
Ключи латиницей?

## Варианты

- (а) отдельный эндпоинт `POST /checks/{name}/versions/{version}/batch`, ключи
  латиницей (`applications`, `stats`), русские — только в текстовых значениях;
- (б) перегрузка существующего `evaluate` (тот же путь, тело с набором заявок);
- (в) оставить как в `batch.feature` (текущая схема с русскими ключами).

## Рекомендация

Отдельный эндпоинт, ключи латиницей (`applications`, `stats`), русские — только
в текстовых значениях.

## Итог

**Решение (2026-09-26):** массовый прогон (batch) — **вне MVP**, пост-MVP/v0.2.

Обоснование:

- в v0.1 единица исполнения — атомарный `evaluate` (принцип атомарной
  композиции, Q20): полный прогон оркестрируется клиентом по манифесту (цикл
  по `active`-версиям → цикл атомарных `evaluate`, Q21), серверный агрегат не
  требуется;
- MVP-минимум REST закрыт Q20 (versioned evaluate + `GET /checks` +
  инфраструктура); сценария пакетного прогона в демо нет — YAGNI;
- схема batch (ключи, агрегаты, частичные ошибки) не стабилизирована, вводить
  её в MVP преждевременно.

Направление на v0.2 (если вернёмся):

- отдельный эндпоинт `POST /checks/{name}/versions/{version}/batch`
  (не перегрузка `evaluate`: путь с параметрами из Q20 не меняется);
- ключи — латиницей (`applications`, `stats`), русские — только текстовые
  значения (принцип Q11);
- ошибки транспорта — конверт Q23; частичные ошибки — целевое состояние
  `batch.feature`.

Следствие: в `rest.rs`/`mcp.rs` ничего не добавляется; `batch.feature` остаётся
целевым состоянием с шапочным комментарием об отсрочке; число файлов и
сценариев не меняется (3 сценария, backend), меняется только статус/приоритет
файла в README.

Полный контекст решения, следствия, сверка с кодом и отклонённые альтернативы —
в [D36](../decisions/D36-batch-deferred.md); краткий канон —
`SPECIFICATION.md` §10, решение №36.
