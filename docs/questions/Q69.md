## Контекст

Корневого `README.md` в репозитории нет — у прототипа отсутствует точка входа
для человека. `docs/README.md` (62 строки) выполняет роль карты, но дублирует
таблицу «Канон чего» из [`../../AGENTS.md`](../../AGENTS.md) §Документы и решения
([D60](../decisions/D60-docs-ownership-sync.md)), пересказывает решения об
архиве журнала ([D61](../decisions/D61-archive-removal.md)) и индексе
([D63](../decisions/D63-journal-index-lifecycle.md)), содержит Q-упоминания
(Q41) и ссылается на `BRIEF.md` ([Q67](Q67.md)). Разведка 29.09.2026 дала
каркас корневого README (~30 строк): что это, быстрый старт, структура, ссылки;
команды сборки/DoD — ссылкой на [`../../AGENTS.md`](../../AGENTS.md) §Сборка,
без дубля.

## Вопрос

Каким должно быть содержимое и объём корневого `README.md` и
[`README.md`](../README.md)?

## Варианты

- (а) корневой README ~30 строк (что это, быстрый старт, структура, ссылки;
  команды — ссылкой на [`../../AGENTS.md`](../../AGENTS.md) §Сборка) +
  `docs/README.md` — лёгкая карта (файлы, «куда за чем», канон — одной ссылкой,
  без дублей и Q-упоминаний);
- (б) корневой расширенный (с описанием инструментов CREDO и синтаксиса);
- (в) только `docs/README.md` отрефакторить, корневой не создавать.

## Рекомендация

Вариант (а). Ссылки на правила журнала — на новое место после [Q67](Q67.md);
объём SPEC/GRAMMAR — по [Q66](Q66.md).
