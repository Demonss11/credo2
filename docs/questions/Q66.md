  [D22](../decisions/D22-rest-paths-canon.md);

Карта разведки: ориентир ≈ 390–400 строк (−57%); §6 (указатель) и §11
(глоссарий, канон [D52](../decisions/D52-glossary-terms-canon.md)) не трогать.
Отдельный вопрос провенанса: §1.3.1 называет источником принципа Q20 →
[D22](../decisions/D22-rest-paths-canon.md), но D22 — «канонические пути REST» —
сомнение разведки, проверить при переносе.

## Вопрос

Каковы объём и принципы ревизии [`SPECIFICATION.md`](../SPECIFICATION.md)?

## Варианты

- (а) по карте: дубли → ссылки на D; §10 → индекс (№ + строка + ссылка;
  «Обоснование» — только в D); §9 → 3 строки + ссылка; §6/§11 не трогать;
- (б) мягко — только §4 и §10;
- (в) агрессивно — до ~300 строк.

## Рекомендация

Вариант (а), без жёсткой цифры (решение владельца), ориентир ≈ 390–400 строк;
отдельно проверить провенанс §1.3.1 (Q20 ↔ [D22](../decisions/D22-rest-paths-canon.md)).
Индекс §10 имеет смысл строить после ретро-D для строк без D — [Q65](Q65.md).
