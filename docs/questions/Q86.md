## Контекст

Разбор прогонов T-16/T-25 (02.10.2026) дал данные по контуру ветвления,
заморозки решений и процесс-коммита — вход программы T-15 (фаза C). Три
критических пункта владельца:

- **P1 — топология веток дочерних задач.** Ветка дочерней задачи создавалась
  от `develop`, а не от ветки незакоммиченного родителя: T-25 (S, снятие
  D65-адресов) стартовала при пустой (без коммитов) ветке T-16 → пакеты задач
  оказались неразделимыми, потребовался совмещённый closeout T-16+T-25
  (F80, F43).
- **P2 — заморозка решений.** Отложенный пакет пересобирался: T-16 git
  «отложено владельцем» (черновик F43/C3) → новая сессия заново разобрала
  закрытие, решение пересматривалось 3× (F81).
- **P3 — session-commit на границе сессии.** Незакрытые процесс-артефакты на
  первом git-вызове новой задачи: обе `branch_start` шли по грязному дереву
  (25 M + 7 ??); в совмещённом пакете исключались чужие пути (F82, F43).
  Требуется первый инкремент C3 — процесс-коммит на границе сессии.

Развилка вынесена владельцу на открытии сервисной операции 03.10.2026
(лента r11). Решение владельца — принять пакет P1+P2+P3.

## Вопрос

Принять ли пакет P1+P2+P3 по разбору T-16/T-25: (P1) топология веток дочерних
задач от ветки родителя, (P2) заморозка отложенных решений на границе сессии,
(P3) session-commit процесс-артефактов первым инкрементом C3 — и в каком
объёме?

## Варианты

- **(A) Принять пакет** — все три пункта: P1 (дочерняя ветка от родителя /
  та же ветка отдельным коммитом; права `analyst` read-only `git branch`/
  `rev-parse`), P2 (стоп-фактор `awaiting_user`/`deferred_by_owner`, сверка
  отложенного пакета первым `analyst`-вызовом новой сессии), P3 (процесс-коммит
  `git` на границе сессии по «постоянному» пакету; остаток C3 — отдельным
  решением).
- **(B) Частично** — принять один-два пункта, остальные отложить.
- **(C) Отложить** — не трогать канон до отдельного решения.

## Рекомендация

Вариант **(A)** — принят владельцем 03.10.2026 (сервисная операция r11):
P1+P2+P3 целиком. Возврат к топологии/заморозке/коммиту без правил — источник
F80–F82 (T-16/T-25). Оформлено
[D89](../decisions/D89-branch-topology-freeze-session-commit.md).
