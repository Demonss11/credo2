## Контекст

S-пилот T-24 (02.10.2026) «чистым» не был, но дал данные для дешёвых правок
канона ролей:

- **Права ↔ потребности проверок (F69):** ~15 `permission.rejected` за прогон —
  `lead` (`git rev-parse`, `agents-perms`, `git ls-remote`), `git`
  (`git branch --list`, `git ls-remote`), `analyst` (`git branch`/`rev-parse`,
  `Get-Content`), `validator` (`tail`); часть проверок осталась косвенной.
- **CCSN `git.push-delete` (F71):** удаление origin-ветки только вручную →
  +2 re-plan `analyst`, эскалация владельцу, прерванный вызов `analyst`,
  ~7 шагов `lead`.
- **Stale state (F67-часть):** сессия началась с T-20-снимка (гейт закрытой
  задачи); `lead` потратил seg0 на разведку и пре-флайт.
- **Модель `#max` (F70):** у `lead` reasoning 112.6k и 43% стоимости прогона
  ($0.212 из $0.489) при `#default` у ролей.

Развилка вынесена владельцу на открытии сервисной операции 02.10.2026
(лента r9): объём пакета правок. Решение владельца — «Сначала дешёвые правки».
