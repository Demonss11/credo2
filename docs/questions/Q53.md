# Q53: Кто ведёт `docs/analysis/findings-registry.md`, если инструкции адресуют его `migrator`, а права роли не покрывают `docs/analysis/**`?

- **Статус:** resolved by [D48](../decisions/D48-findings-registry-owner.md)
- **Дата:** 2026-09-28
- **Приоритет:** 🟡 важно
- **Связано:** [D48](../decisions/D48-findings-registry-owner.md);
  [`findings-registry.md`](../analysis/findings-registry.md) (F39);
  [`migrator.md`](../../.opencode/agents/migrator.md);
  [`AGENTS.md`](../../AGENTS.md) §«Рабочая группа агентов»;
  [`memorandum-W8-run5.md`](../analysis/memorandum-W8-run5.md) §2 (F39), §5.7
- **Источник:** исполнение журнала Run 5 (28.09.2026) — `migrator` получил
  `permission.rejected` на `edit docs/analysis/findings-registry.md`

## Контекст

Меморандумы адресуют обновление реестра находок роли `migrator`, но её
фронтматтер запрещал запись в `docs/analysis/**` (`permission.rejected`) — реестр
до этого правили сервисные/доковые записи. Реестр — точка правды по ID находок;
без роли-владельца он «зависает» между сервисной сессией и `migrator` (находка
F39, аналог F16).

## Вопрос

Кто ведёт `docs/analysis/findings-registry.md`, если инструкции адресуют его
`migrator`, а права роли не покрывают `docs/analysis/**`?

## Варианты

- (а) **оставить сервисной сессии** — инструкции меморандумов продолжают
  расходиться с правами; роль-владелец не определена;
- (б) **право `edit docs/analysis/findings-registry.md` для `migrator`** —
  синхронизация «Пишет в» в `AGENTS.md` и тела роли;
- (в) **выделить реестр в `docs/questions/`** — меняет канон расположения улик и
  ломает существующие ссылки меморандумов.

## Рекомендация

Вариант (б): минимальное право приводит «инструкция ↔ права» в соответствие и
закрепляет за журналом роль-владельца реестра; F39 — прямой аналог F16.

## Итог

Принят вариант (б). Решение владельца — 2026-09-28. Полный контекст, следствия,
сверка (⚪ — права/процесс) и отклонённые альтернативы — в
[D48](../decisions/D48-findings-registry-owner.md); краткий канон —
[`SPECIFICATION.md`](../SPECIFICATION.md) §10, решение №48.
