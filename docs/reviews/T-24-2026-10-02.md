## Находки

**P1 — `tests/rest_cli.rs:47` — `clippy::collapsible_if` → `cargo clippy
--all-targets -- -D warnings` красный → DoD не воспроизведён.**
`RestServer::wait_ready` использует вложенный `if let Ok(...) { if body.contains(...) { return; } }`;
clippy (rust-1.96.0) требует схлопнуть через let-chain:
`if let Ok((200, body)) = request(...) && body.contains("ok") { return; }`.
Последствие: гейт `clippy --all-targets -- -D warnings` падает на компиляции
тест-таргета `rest_cli` — задача не может быть принята. Правка — в `tests/**`
(зона `tester`); `tester` clippy не запускал (не в правах роли), поэтому дефект
не был пойман до приёмки.
