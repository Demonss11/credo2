Собери read-only обзор репозитория:

- `git status -sb` — текущая ветка, синхронизация, изменённые/untracked (сводно);
- `git branch -a` — локальные и удалённые ветки;
- `git tag -l "session/*"` — теги чекпойнтов сессий (`git-workflow.md`
  §«Session-commit»);
- `git log -5 --oneline` — последние коммиты.

Изменяющих команд не выполняй. Верни компактный отчёт: ветка и синхронизация,
сводка изменений, ветки, теги сессий, последние коммиты.
