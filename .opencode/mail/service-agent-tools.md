# Сервисная лента: service-agent-tools (инструменты экономии токенов)

**Назначение:** пакет инструментов ролей: (1) скрипт
`.opencode/scripts/agents-perms.mjs` — компактная сводка прав агентов вместо
сырого `opencode debug agents` (122 КБ / 2617 строк JSON с полными
`system`-промптами); (2) каноничная форма подсчёта строк файла
`rg -c '^' <файл>` (вместо `powershell -Command "… | Measure-Object …"`,
которая отклоняется правами как составная).
**Основание:** наблюдения владельца 29.09.2026: (1) `docs-writer` получил
`Permission denied` на powershell-подсчёт строк; (2) `auditor` — огромный вывод
`opencode debug agents` со срезом token-guard и недоступным полным файлом.
**Решения владельца:** пакет целиком; сырой `opencode debug agents` **убрать**
у `validator` и `auditor` (при сбое скрипта — эскалация).
**Факты (замеры сервисной сессии):** `opencode debug agents` → 122 511 Б,
2617 строк, JSON-массив 18 агентов (`id,name,model,request,system,description,
mode,hidden,color,steps,permissions`); прототип сводки → 1 883 Б (18 строк);
`rg -c '^' .opencode/mail/service-dod-scope.md` → `272` (рабочая форма);
`rg -c ""` в PowerShell теряет пустой аргумент — не использовать.
**Маршрут:** `migrator` (Q56/D51) → сервисная сессия (скрипт + правки канона:
`validator.md`, `auditor.md`, `review.md`, `workspace.md`) → `auditor` (аудит)
→ `validator` (приёмка + смоук скрипта) → `git`.

Формат записей — `AGENTS.md` §«Память и почта».
