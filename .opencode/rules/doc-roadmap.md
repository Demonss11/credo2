# Правила: Roadmap

**Когда читать:** правка `.gitverse/ROADMAP.md`.

## Расположение

- Единственный файл — `.gitverse/ROADMAP.md`.
- Отложенные шаги — не сюда, а в `.gitverse/ТЕХДОЛГ.md` (ведёт
  `@secretary`).
- Общее — `doc-common.md`.

## Структура

```md
# ROADMAP

**Стратегия разработки:** <одна фраза>.

## Общие статусы

<легенда: что означают статусы версий и пунктов>

### vX.Y – <Название этапа>

- [ ] <проверяемый результат>
- [x] <выполненный результат>
```

## Правила содержания

- Пункт — результат, а не активность: «инструменты `state.*` работают», а
  не «делать инструменты».
- Один пункт — один проверяемый итог.
- Версии идут по возрастанию; завершённые этапы не удаляй, помечай `[x]`.
- Легенда статусов — в шапке файла, не дублировать в каждом этапе.

## Чек-лист

- [ ] Пункты сформулированы как проверяемые результаты.
- [ ] Порядок версий не нарушен.
- [ ] Отложенные шаги не попали в ROADMAP вместо ТЕХДОЛГ.
