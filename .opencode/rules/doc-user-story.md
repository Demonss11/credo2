# Правила: User Story

**Когда читать:** оформление пользовательской истории.

## Расположение

- `docs/**` или `.gitverse/docs/**`; связывай с ФТ (`doc-spec.md`).
- Общее — `doc-common.md`.

## Формат

```md
## US-<N>: <короткое имя>

**Как** <роль>, **я хочу** <действие>, **чтобы** <ценность>.

**Критерии приёмки:**

- Given <условие>, When <действие>, Then <результат>.
- Given <условие>, When <действие>, Then <результат>.

**Связанные требования:** FR-<N>.
```

## Правила содержания

- Одна story — одна ценность и одна роль.
- Ценность в «чтобы» объясняет, зачем, а не повторяет действие.
- Критерии приёмки — проверяемые сценарии Given/When/Then.
- Story соответствует INVEST: независима, обсуждаема, ценна, оцениваема,
  мала, тестируема.
- Story не дублирует ФТ, а ссылается на него по ID.

## Чек-лист

- [ ] Есть роль, действие и ценность.
- [ ] Критерии приёмки проверяемы.
- [ ] Story связана с требованиями по ID.
- [ ] Отсутствуют дубли с соседними story.
